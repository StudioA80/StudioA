DADOS E BACKUP
A atualização não remove o localStorage nem apaga a base IndexedDB. Antes de publicar, exporte um backup no app atual. Não limpe os dados do site/navegador para forçar atualização. A restauração de backup substitui os dados atuais e deve ser feita somente após exportar uma cópia de segurança.

PUBLICAÇÃO
Extraia este ZIP e envie os sete arquivos/pastas para a raiz do repositório StudioA80/StudioA, mantendo icons/ e substituindo os arquivos com os mesmos nomes. Aguarde o GitHub Pages e abra a URL HTTPS publicada.

LIMITAÇÃO
A validação estática e os testes automatizados incluídos no processo não substituem testes finais no navegador Android com uma cópia real da base do usuário. Não considere o app homologado sem testar cadastro, edição, agenda, atendimento, estoque, backup/restauração e modo offline no aparelho.
